Privacy policy for twitch-vods

twitch-vods is a personal script that runs only on its owner's computer and is used only by its owner.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload videos to the owner's own channel, create playlists there, and check whether uploads have finished processing.

What it stores

The sign-in token Google issues is saved only on the owner's computer. No data is sent to, stored on, or shared with any server other than Google's own YouTube services.

Revoking access

Access can be removed at any time from Google Account → Third-party connections.

Google API use complies with the Google API Services User Data Policy.
